🎯 Características Principales del Sistema

🔐 Autenticación y Control de Acceso

  • Login tipo Admin y Centro
  • Credenciales en Google Sheets
  • Tokens JWT en localStorage
  • Restricción de datos por rol

📊 Gestión de Usuarios

  • Admin crea usuarios por centro
  • Cada usuario solo ve su centro
  • Lista de usuarios creados
  • Validaciones de datos

📋 Registro de Recetas

  • Formulario autocomplete
  • Validación de campos
  • Envío a Google Sheets
  • Formateo de códigos (5 dígitos)

📊 Catálogos y Datos

  • Establecimientos desde Excel
  • Medicamentos desde JSON
  • Tipos de servicio desde Excel
  • Cache en navegador local

🔍 Búsqueda y Filtrado

  • Autocompletado de productos
  • Filtros en tabla de datos
  • Búsqueda en tiempo real
  • Debounce optimizado

☁️ Integración Google

  • Google Apps Script backend
  • Google Sheets como BD
  • Sincronización en tiempo real
  • Respuestas JSON

📚 Leyenda de Componentes

Frontend: Interfaz del usuario (HTML, CSS, JavaScript)
Backend: Google Apps Script (lógica de servidor)
Base de Datos: Google Sheets (almacenamiento)
LocalStorage: Almacenamiento en navegador del cliente
Catálogos: Datos estáticos cargados desde Excel/JSON
Auth: Sistema de autenticación y autorización

⚡ Flujo Rápido de Uso

Paso 1: 👨‍💼 Admin se autentica con usuario: admin / admin123

Paso 2: ⚙️ Admin abre "Gestión de Usuarios" y crea usuario para cada centro

Paso 3: 🏥 Usuario del Centro se autentica con sus credenciales

Paso 4: 📋 Completa formulario de Receta No Atendida

Paso 5: 💾 Guarda registro → se almacena en Google Sheets

Paso 6: 📊 Datos aparecen en tabla (solo su centro si es usuario, todos si es admin)
