🔐 Flujo de Autenticación

1

Usuario abre la aplicación

index.html se carga en el navegador

⬇️
2

¿Está autenticado?

Se verifica si existe token en localStorage

⬇️
3

Mostrar Login o Aplicación

Si NO está autenticado: Muestra pantalla de login

Si está autenticado: Muestra aplicación principal

⬇️
4

Seleccionar tipo de acceso

Elige entre: ADMIN o CENTRO DE SALUD

⬇️
5

Ingresar credenciales

Admin: usuario: admin, contraseña: admin123

Centro: Selecciona centro, usuario y contraseña

⬇️
6

Enviar a Google Apps Script

Se validan las credenciales contra Sheet USUARIOS

⬇️
7

✅ Login exitoso

Se crea token JWT y se guarda en localStorage. Se accede a la aplicación

📝 Flujo: Registrar una Receta

1

Usuario Centro completa formulario

COD PRE, Producto, Cantidad, Motivo, Tipo Servicio, etc

⬇️
2

Click en "Guardar Receta"

Script.js valida que todos campos estén llenos

⬇️
3

Formateo de datos

- COD PRE: Se formatea a 5 dígitos (1 → 00001)

- Código Producto: Se formatea a 5 dígitos (91 → 00091)

⬇️
4

POST a Google Apps Script

Se envía JSON con todos los datos formateados

⬇️
5

Google Apps Script procesa

Valida, verifica centro existe, verifica campos obligatorios

⬇️
6

✅ Inserta en Google Sheets

Nueva fila en Sheet ENTRADAS/RECETAS con todos datos formateados

⬇️
7

✅ Confirmación al usuario

Muestra "Receta guardada exitosamente" y limpia formulario

✨ Características Especiales

🎯 Autocompletado Inteligente

Mientras escribes en los campos, el sistema sugiere:

  • Establecimientos: De catalogo_establecimientos.json
  • Medicamentos: De medicamentos.json con código
  • Tipos de Servicio: De tipos_servicio.xlsx

🔄 Formateo Automático

Los códigos se convierten automáticamente a 5 dígitos:

Usuario ingresa: 1 → Sistema guarda: 00001 Usuario ingresa: 91 → Sistema guarda: 00091 Usuario ingresa: 123 → Sistema guarda: 00123

🔒 Control de Acceso

El sistema restringe datos por centro automáticamente:

  • Admin: Ve TODOS los registros de todos centros
  • Usuario Centro: Ve SOLO registros de su centro (filtrado en JavaScript)
