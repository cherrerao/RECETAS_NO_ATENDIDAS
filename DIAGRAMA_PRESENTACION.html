🏥 Recetas No Atendidas

Sistema de Gestión para Centros de Salud

👨‍💼

Paso 1: Admin Crea Usuarios

El administrador crea un usuario para cada centro de salud con sus credenciales

⬇️
🏥

Paso 2: Centro Ingresa

El usuario del centro se autentica con sus credenciales en el sistema

⬇️
📝

Paso 3: Registra Receta

Completa un formulario con los datos de la receta no atendida

⬇️
☁️

Paso 4: Se Guarda

El registro se almacena automáticamente en la base de datos en la nube

👥 ¿Quién puede usar el sistema?

👨‍💼

ADMINISTRADOR

Persona encargada de gestionar

  • Crear usuarios por centro
  • Ver TODOS los datos
  • Gestionar accesos
  • Usuario: admin
🏥

CENTRO DE SALUD

Persona del centro que registra

  • Registrar recetas
  • Ver SUS recetas
  • Buscar medicamentos
  • Sin acceso a otros

📋 ¿Qué datos se guardan?

Datos de la Receta:

  • ✓ Centro de Salud - ¿De dónde viene?
  • ✓ Medicamento - ¿Cuál no se atendió?
  • ✓ Cantidad - ¿Cuántas unidades?
  • ✓ Motivo - ¿Por qué no se atendió?

Información Adicional:

  • ✓ Tipo de Servicio - Ambulatoria, hospitalaria, etc
  • ✓ Fecha - Cuándo se registró
  • ✓ Código Medicamento - Código único del producto
  • ✓ Observaciones - Notas adicionales
