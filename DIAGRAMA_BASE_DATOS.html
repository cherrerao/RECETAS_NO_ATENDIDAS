ℹ️ Importante

Las hojas RECETAS y ENTRADAS sirven para el mismo propósito (compatibilidad). El sistema escribe en ambas. La hoja USUARIOS almacena las credenciales para la autenticación.

Almacena credenciales y roles de acceso al sistema

Campo Tipo Descripción Ejemplo

rol * String Tipo de acceso: "admin" o "usuario" usuario
centro ⚠️ String Centro asignado (solo para usuarios, no admin) Centro de Salud Bellavista

producto * String Nombre del medicamento ACIDO ACETILSALICILICO

usuario_registro ⚠️ String Quién registró el dato bellavista

📝 Formato de COD PRE y Código Producto

Los códigos se formatean automáticamente a 5 dígitos con ceros a la izquierda:

Entrada: 1 → COD PRE: 00001 Entrada: 123 → COD PRE: 00123 Entrada: 91 → CODIGO PRODUCTO: 00091 Entrada: 2 → CODIGO PRODUCTO: 00002

5️⃣ Funciones Principales en Google Apps Script

GET Handler - Obtener Datos

Maneja las solicitudes GET para recuperar información

Parámetros: - action=getUsers → Obtiene lista de usuarios - action=getRecetas → Obtiene todas las recetas - action=cargarCentros → Obtiene lista de centros Respuesta: { "status": "success", "data": [ {...}, {...} ] }

POST Handler - Guardar Datos

Maneja las solicitudes POST para crear/actualizar registros

Acciones soportadas: - createUser → Crear nuevo usuario - saveReceta → Guardar receta no atendida - login → Validar credenciales Recibe JSON con los datos, Valida, Inserta en Sheets, Retorna: { "status": "success", "message": "..." }

Función: getUsers

Retorna lista de todos los usuarios del sistema

function obtenerUsuarios() { const sheet = getSheet(SHEET_USUARIOS); const datos = sheet.getDataRange().getValues(); // Convierte a objetos JSON const usuarios = datos.map(fila => ({ usuario: fila[0], rol: fila[2], centro: fila[3], activo: fila[4] })); return respuestaJSON({ status: 'success', data: usuarios }); } Retorna: [ { usuario: "admin", rol: "admin", centro: null }, { usuario: "bellavista", rol: "usuario", centro: "..." }, ... ]

Función: getRecetas

Retorna todos los registros de recetas

function obtenerRecetas() { const sheet = getSheet(SHEET_RECETAS); const datos = sheet.getDataRange().getValues(); // Primera fila es encabezado, las demás son datos const recetas = datos.slice(1).map(fila => ({ cod_pre: fila[0], establecimiento: fila[1], codigo_producto: fila[2], producto: fila[3], cantidad: fila[4], ... })); return respuestaJSON({ status: 'success', data: recetas, total: recetas.length }); }

🔒 Seguridad y Restricciones de Acceso

Función Admin Usuario Centro
Crear Usuarios ✅ Sí (solo admin) ❌ No
Ver Gestión Usuarios ✅ Sí (botón visible) ❌ No (botón oculto)
Ver Todas Recetas ✅ Sí (todos centros) ❌ No (filtrado en JS)
Ver Recetas su Centro ✅ Sí ✅ Sí
Crear Receta ✅ Sí (cualquier centro) ✅ Sí (solo su centro)
Acceso a Apps Script ✅ Tiene editor ❌ Sin acceso

⚠️ Nota sobre Seguridad

El filtrado por centro en usuarios se hace en el JavaScript frontend. Para mayor seguridad, deberías validar el centro en el backend (Apps Script) también.
